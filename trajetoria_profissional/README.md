# Plano de Carreira Interativo com IA • Profª Roberta

Aplicação desenvolvida para atender aos requisitos da disciplina:

- **Item 1:** Ferramenta web interativa com assistente conversacional de IA.
- **Item 2:** Desenho de carreira desde o início profissional até 5 anos pós-graduação.
- **Item 3:** Diagnóstico estruturado com Matriz SWOT e ciclo PDCA.
- **Item 4:** Carreira em Y (Especialista Técnico) e modelo T-Shaped.
